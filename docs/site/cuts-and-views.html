Cuts & Views

A cut is a cheap view over a finished tree. It does not rebuild linkage. Every cut still covers every leaf exactly once.

Defaults

Usual top cut: top_criterion="optimal" scored with Calinski–Harabasz. Width: min_width=3, max_width=7, target_width=5. Depth: max_depth=4. Pass a saved feature matrix. If you do not have one, pass cophenetic distances and say so — do not drop to silhouette.

Feature matrix first

Optimal cuts score how clean a partition is. That score is only as good as the matrix you give it. After build, matrices live on orchard.layer_matrices. To still have them after save/load, set layer_matrix_persist="always" at build time (see Persistence).

Typical keys:

  • description_minilm_centered_cosine — MiniLM semantic layer
  • tfidf_cosine — lexical TF-IDF layer
  • domain_raw_js / function_raw_js — taxonomy layers

Any of these is an [n, n] similarity matrix. Passing it as feature_matrix treats each row as that document’s feature vector. That is the intended input for Calinski–Harabasz.

Top-level cut: three options

build_dynamic_cut always needs top_criterion. Use optimal unless you have a reason not to.

1. optimal (usual)

Input: tree + feature matrix + width bounds.
Procedure: search cluster counts in [min_width, max_width] (at least 2). Keep the Calinski–Harabasz winner. Then recursively subcut with the same rule until width or max_depth stops it.
Result: a nested cut. Read cut["top_partition_count"] and cut["cut_optimizer"].

from orchard import build_dynamic_cut, validate_dynamic_cut

X = orchard.layer_matrices["description_minilm_centered_cosine"]
cut = build_dynamic_cut(
    tree,
    top_criterion="optimal",
    cut_optimizer="calinski_harabasz_score",
    feature_matrix=X,
    min_width=3,
    max_width=7,
)
validate_dynamic_cut(cut, tree)
print(cut["top_partition_count"], cut["cut_optimizer"])
# cut_optimizer should be calinski_harabasz_score

No saved matrix: Calinski–Harabasz on cophenetic distances

This is a weaker input. It is still Calinski–Harabasz. It is not silhouette. Print that you used cophenetic distances so the fallback is visible.

from scipy.cluster.hierarchy import cophenet
from scipy.spatial.distance import squareform

if "description_minilm_centered_cosine" in orchard.layer_matrices:
    X = orchard.layer_matrices["description_minilm_centered_cosine"]
    source = "saved MiniLM layer"
else:
    X = squareform(cophenet(tree.linkage))
    source = "cophenetic distances (no saved layer matrix)"

cut = build_dynamic_cut(
    tree,
    top_criterion="optimal",
    cut_optimizer="calinski_harabasz_score",
    feature_matrix=X,
)
print("optimal cut features:", source)
print(cut["cut_optimizer"], cut["top_partition_count"])
Do not omit feature_matrix.

With no matrix, top_criterion="optimal" currently selects silhouette on cophenetic distances. That silent switch is the wrong default — cut quality (and how useful the tree looks) changes a lot. Always pass cut_optimizer="calinski_harabasz_score" and a matrix.

Other named scorers exist (silhouette_score, davies_bouldin_score) only if you pass them on purpose. cut_polarity=-1 flips “higher is better” for metrics like Davies–Bouldin. Default polarity is 1 (higher is better), which matches Calinski–Harabasz.

2. cluster_count

You pick the number of top groups. No optimizer.

Required: cluster_count (1 … number of leaves).
Also required: target_width (must sit inside min_width…max_width).

cut = build_dynamic_cut(
    tree,
    top_criterion="cluster_count",
    cluster_count=4,
    min_width=1,
    max_width=8,
    target_width=4,
)

3. distance_threshold

You pick a linkage height. Provide exactly one of:

  • distance_threshold — raw height
  • distance_threshold_normalized — fraction of root height, in [0, 1]
cut = build_dynamic_cut(
    tree,
    top_criterion="distance_threshold",
    distance_threshold_normalized=0.4,
    min_width=3,
    max_width=7,
    target_width=5,
)

Width and depth

ArgumentDefaultRole
min_width3Lower bound on groups at a cut.
max_width7Upper bound. Optimal search uses this as max k.
target_width5Preferred width for non-optimal subcuts. Optional when optimal.
max_depth4Stop recursing.
threshold_steps32How many candidate heights to try for non-optimal subcuts.

Walk labels by level

Use these while comparing trees, before or after labeling. If no label set is active, internal nodes show a short id and leaves show item_id.

Whole tree, with or without leaves

from collections import defaultdict
from orchard.tree import default_node_label

def nodes_by_level(tree, include_leaves=True, label_set=None):
    levels = defaultdict(list)

    def walk(node_id, depth):
        node = tree.node(node_id)
        if include_leaves or node["kind"] != "leaf":
            levels[depth].append(
                (node_id, default_node_label(tree, node_id, label_set=label_set))
            )
        for child in node.get("children") or []:
            walk(child, depth + 1)

    walk(tree.root_node_id, 0)
    return dict(levels)

for depth, rows in sorted(nodes_by_level(tree, include_leaves=False).items()):
    print(depth, [label for _node_id, label in rows])

# include leaves (documents) at the bottom levels
for depth, rows in sorted(nodes_by_level(tree, include_leaves=True).items()):
    print(depth, [label for _node_id, label in rows])

Walk a cut

walk_cut_json is the built-in helper: nested dict of labels under the cut, optional max_depth.

from orchard import walk_cut_json

summary = walk_cut_json(cut, tree)                 # uses active label set, or ids
summary = walk_cut_json(cut, tree, max_depth=2)    # stop early
summary = walk_cut_json(cut, tree, label_set="intrinsic_v1")

Other views

Validate

from orchard import validate_dynamic_cut
validate_dynamic_cut(cut, tree)   # exact leaf partition; canonical ids

Leaf groups at the top cut

from orchard import cut_partition_item_ids
groups = cut_partition_item_ids(cut, tree)
# list of lists of item_id; union is the full corpus, no overlap

Pack a presentation frontier

from orchard import pack_canonical_tree
packed = pack_canonical_tree(tree, target_exposed_clusters=4, max_depth=3)

Subtree

Same canonical IDs as the parent tree. You can cut a subtree the same way.

sub = tree.subtree(node_id)
