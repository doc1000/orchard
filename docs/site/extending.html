Extending Orchard

Swap one stage at a time. Keep MiniLM (semantic) distinct from TF-IDF (lexical) and from ModernBERT (taxonomy features).

Taxonomy scorer

  • Primary: define labels, train a ModernBERT+logistic head from descriptions and/or labelled chunks, load_head — Taxonomies.
  • Optional: packaged Domain / Function heads.
  • Or implement transform(documents) -> ndarray with a name and label_order.

Document embedding

  • Default online: MiniLMEmbeddingBackend (encode(texts) -> ndarray).
  • Lexical opt-in: TfidfEmbeddingBackend().
  • Any object with encode(texts) can be passed as embedding_backend.

Fusion and family

  • Override per-tree fusion with profiles={tree_id: SimilarityProfile(name=..., weights={...})}. Weights must sum to 1. See Set fusion weights.
  • family_metadata_key opts into app_exact_match (complete metadata required).
  • Diagnostic MiniLM: description_transform="raw"|"whitened"|"centered_pc3" (default stays "centered").

Trees you did not build here

  • Tree.from_linkage then Orchard.from_trees.
  • Named label sets without rebuilding (Labels).
  • Keep layer matrices if you will run Calinski–Harabasz cuts (Persistence).
