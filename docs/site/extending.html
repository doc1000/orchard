Extending Orchard

  • Swap taxonomy JSON or implement transform(documents) -> ndarray
  • Pass a custom embedding_backend with encode(texts) -> ndarray (MiniLM default; TfidfEmbeddingBackend() is the lexical opt-in)
  • Override per-tree SimilarityProfile / weight maps; weights must sum to 1 (never silently repaired)
  • Set family_metadata_key to opt into app_exact_match (complete metadata required)
  • Diagnostic MiniLM: description_transform="raw"|"whitened"|"centered_pc3" (default stays "centered")
  • Start from external linkage via Tree.from_linkage
  • Add named label sets without rebuilding trees

See CODE_MANIFEST.md for the module map.
