Multiple Trees

One Orchard is one document corpus and one or more named trees over that same leaf set.

Defaults

Online OrchardBuilder().build emits domain and function. A no-taxonomy tree named semantic is added only if taxonomies=[] or include_semantic_with_taxonomies=True (default False). There is never a tree named fused.

Read trees

orchard.tree_ids          # sorted names
orchard.tree("domain")
orchard.trees             # dict[str, Tree]

Every tree’s item_ids must match the orchard documents exactly.

Compare two named trees

Same documents, different signals — compare linkage before labeling.

domain = orchard.tree("domain")
function = orchard.tree("function")
print(domain.linkage_fingerprint() == function.linkage_fingerprint())

External linkage

If you already have a SciPy Z matrix, skip the builder.

from orchard import Orchard, Tree

tree = Tree.from_linkage(Z, item_ids=item_ids, tree_id="custom", documents=documents)
orchard = Orchard.from_trees(documents=documents, trees={"custom": tree})
