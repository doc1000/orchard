Visualization

Orchard emits Plotly-oriented data payloads without importing Plotly.

from orchard import cut_to_plotly_structure, orchard_plotly_structures

structure = cut_to_plotly_structure(tree, cut, cut_id="overview")
multi = orchard_plotly_structures(orchard, {"domain": cut_a, "function": cut_b})
