Visualization

Orchard emits Plotly-oriented data payloads. It does not import Plotly. Labels are optional; unlabeled trees still plot using ids.

Defaults

Display text comes from the active label set, or default_node_label (leaf item_id / short internal id). Build a cut first — see Cuts & Views.

One tree + one cut

from orchard import build_dynamic_cut, cut_to_plotly_structure

X = orchard.layer_matrices["description_minilm_centered_cosine"]
cut = build_dynamic_cut(
    tree,
    top_criterion="optimal",
    cut_optimizer="calinski_harabasz_score",
    feature_matrix=X,
)
structure = cut_to_plotly_structure(tree, cut, cut_id="overview")

Several trees

from orchard import orchard_plotly_structures

multi = orchard_plotly_structures(
    orchard,
    {"domain": cut_a, "function": cut_b},
)

For a nested label dict without Plotly, use walk_cut_json on Cuts & Views.
