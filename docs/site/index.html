Getting Started

Local-first hierarchical trees over a fixed document corpus. Build structure first. Name nodes later.

Install

uv pip install -e ".[dev]"

Online defaults (MiniLM document embedding + packaged ModernBERT taxonomy heads):

uv pip install -e ".[dev,ml]"
Defaults

With orchard[ml], OrchardBuilder().build(documents) builds domain and function trees from fused MiniLM (semantic) + TF-IDF (lexical) + ModernBERT taxonomy scores. No labels are attached. Layer matrices are not saved unless you set layer_matrix_persist="always".

Minimal example (online)

from orchard import OrchardBuilder

documents = [
    "Schedule a calendar reminder for tomorrow morning.",
    "Send an email summary of the weekly status notes.",
    "Create a task to review the draft proposal.",
    "Find documents mentioning quarterly budget planning.",
]
builder = OrchardBuilder(layer_matrix_persist="always")
orchard = builder.build(documents)
print(orchard.tree_ids)       # ('domain', 'function')
domain = orchard.tree("domain")
orchard.save("artifacts/demo_orchard")

That domain tree has linkage only. Inspect it, cut it, compare it. Then see Labels.

Minimal example (offline, explicit)

Clean environments without extras must opt in. This path is lexical: cue-word taxonomy JS and/or TF-IDF. It is not MiniLM and not ModernBERT.

from orchard import OrchardBuilder

orchard = OrchardBuilder(allow_offline_fallback=True).build(documents)
print(orchard.tree_ids)  # ('domain', 'function')
# taxonomy_transform == "cue"

No-taxonomy trees

Semantic embedding (MiniLM)

orchard = OrchardBuilder(taxonomies=[]).build(documents)
tree = orchard.tree("semantic")
# MiniLM 0.66 / TF-IDF 0.34

Lexical embedding (TF-IDF)

from orchard.backends.tfidf import TfidfEmbeddingBackend

orchard = OrchardBuilder(
    taxonomies=[],
    embedding_backend=TfidfEmbeddingBackend(),
).build(documents)
tree = orchard.tree("semantic")  # name only; vectors are TF-IDF

The tree id "semantic" means “no taxonomy.” It does not mean the embedding is semantic. Details: Building Trees.
