Persistence

An Orchard saves as a versioned directory plus a manifest, not one giant JSON blob. Layer matrices are optional — keep them if you will run optimal cuts later.

Defaults

Always written: documents, each tree’s linkage + canonical nodes, named label sets, build metadata. Layer matrices: layer_matrix_persist="never" — they exist in memory after build, but save does not write them. For Calinski–Harabasz cuts after reload, use "always".

Save and load

from orchard import Orchard

orchard.save("artifacts/my_orchard")
loaded = Orchard.load("artifacts/my_orchard")

Input: a directory path (created if needed).
Result: manifest.json, documents.json, trees/<tree_id>/canonical_tree.json, linkage.json, optional labels/*.json, optional layer_matrices.npz.

Always durable

  • Normalized documents
  • Linkage (Z matrix + leaf order)
  • Canonical node registry
  • Named label sets and which set is active
  • Build metadata (get_params(), fusion weights, checksums)

Layer matrices

These are the [n, n] similarity layers computed during build (MiniLM, TF-IDF, taxonomy JS, optional app-family). Optimal cuts want them as feature_matrix. Recomputing MiniLM / ModernBERT just to cut is slow; saving the matrices is the fast path.

Set the policy on the builder. It is stored in orchard metadata and used at save time.

never (default)

Do not write layer_matrices.npz. After load, orchard.layer_matrices is empty. You can still cut from linkage, but then you should pass cophenetic distances into Calinski–Harabasz explicitly — see Cuts.

OrchardBuilder()  # layer_matrix_persist="never"

always (recommended if you will cut)

from orchard import OrchardBuilder

builder = OrchardBuilder(layer_matrix_persist="always")
orchard = builder.build(documents)
orchard.save("artifacts/my_orchard")
# artifacts/my_orchard/layer_matrices.npz

loaded = Orchard.load("artifacts/my_orchard")
X = loaded.layer_matrices["description_minilm_centered_cosine"]

below_size_limit

Write the NPZ only if total bytes ≤ 8 MiB. If larger, skip the file (same end state as never for that save). Checksums still stay in metadata.

OrchardBuilder(layer_matrix_persist="below_size_limit")

compressed

Always write, using np.savez_compressed. Smaller file, slower IO.

OrchardBuilder(layer_matrix_persist="compressed")

In-memory orchard.layer_matrices is filled by build regardless of policy. The policy only decides whether save keeps them.
