Persistence

Orchard saves a versioned artifact directory + manifest (not one giant JSON blob).

orchard.save("artifacts/my_orchard")
loaded = Orchard.load("artifacts/my_orchard")

Durable: documents, linkage, node registry, named label sets, build metadata.
