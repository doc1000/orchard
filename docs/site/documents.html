Documents

Every build starts from a finite list of documents. One document becomes one leaf in every tree.

Defaults

Only text is required. Missing item_id is generated stably from the text. Empty title and empty metadata are fine. The corpus cannot change after build.

Load from a list

Input: a Python list of strings, dicts, or Document objects.
Result: canonical Document records, ready for OrchardBuilder.build.

List of strings

from orchard import OrchardBuilder

documents = [
    "Schedule a calendar reminder for tomorrow morning.",
    "Send an email summary of the weekly status notes.",
    "Create a task to review the draft proposal.",
    "Find documents mentioning quarterly budget planning.",
]
orchard = OrchardBuilder().build(documents)

Each string becomes Document(text=...). IDs are hashed from the text.

List of dicts

from orchard.adapters import documents_from_records

documents = documents_from_records([
    {"text": "Send an email digest.", "item_id": "mail-1", "title": "Digest"},
    {"text": "Create a calendar event.", "item_id": "cal-1", "metadata": {"app_name": "calendar"}},
])

List of Document objects

from orchard import Document

documents = [
    Document(text="Find related notes", title="Search", metadata={"topic": "notes"}),
    Document(text="Archive last week's mail", item_id="mail-archive"),
]

OrchardBuilder.build accepts any of these forms directly. You do not have to wrap strings first.

IDs must be unique. Duplicate IDs raise. For the optional app-family layer, every document must have a non-empty metadata[family_metadata_key] — see Building Trees.

Load from files

Same destination: a list of Document. See Adapters for CSV / JSON / JSONL / directory details.

from orchard.adapters.loaders import load_documents

docs = load_documents(documents)          # already a list: returned as Documents
docs = load_documents("corpus.jsonl")
docs = load_documents("notes/")           # directory of *.txt
