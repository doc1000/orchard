Taxonomies

Defaults ship as replaceable JSON under orchard/assets/taxonomies/.

from orchard import DomainTaxonomy, FunctionTaxonomy, TaxonomyModel

domain = DomainTaxonomy.load_default()
function = FunctionTaxonomy.load_default()
custom = TaxonomyModel.load("path/to/domain.json")

Cue-based transform is offline. Optional fit(documents, labels_by_item_id) trains a TF-IDF logistic head.
