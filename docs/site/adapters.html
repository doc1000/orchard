Adapters

Adapters only turn files or records into Document lists. They do not build trees. For an in-memory list, see Documents.

Defaults

CSV text column is text; optional item_id, title, source; other columns become metadata. Directory glob is *.txt; file stem becomes item_id and title. Encoding utf-8.

Dispatch helper

from orchard.adapters.loaders import load_documents

docs = load_documents(records)         # list of str / dict / Document
docs = load_documents("corpus.jsonl")
docs = load_documents("corpus.json")
docs = load_documents("corpus.csv")
docs = load_documents("notes/")        # directory

Explicit loaders

from orchard.adapters import (
    documents_from_csv,
    documents_from_directory,
    documents_from_json,
    documents_from_jsonl,
    documents_from_records,
)

docs = documents_from_records([
    "plain text item",
    {"text": "Send an email digest.", "item_id": "mail-1"},
])
docs = documents_from_csv("corpus.csv")
docs = documents_from_directory("notes/", glob="*.txt")
docs = documents_from_jsonl("corpus.jsonl")

All of these feed OrchardBuilder.build(...).
