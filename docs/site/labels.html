Labels

Labeling names nodes on a tree you already built. It does not change linkage. Do this before you judge a cut — without names there is little basis for saying the cut is good.

Defaults

build does not label. There is no active label set until you create one. Intrinsic helper name: "intrinsic_v1". Import helper name: "imported". Both make the new set active unless you pass make_active=False. Contrastive / LLM labeling is not in v1.

After build, before you trust a cut

Linkage is the expensive commitment. Names are cheap overlays and never mutate it. Fingerprints can compare two linkages unlabeled. Reading whether a partition makes sense needs labels on the nodes — see walk by level.

  1. Build one or more trees.
  2. Attach a named label set (this page).
  3. Walk / cut / compare. Score cuts with Calinski–Harabasz.

Online vs offline labeling

Online (intended)

An LLM names internal nodes from member texts. MiniLM and ModernBERT are already used in building; the LLM is for this step. Orchard does not ship an LLM labeler in v1. Plug one in later as another named set.

Offline (available now)

label_intrinsic — short token summaries from titles/text, rolled up the tree. Or import_labels — you supply the strings.

Intrinsic labels

Input: a Tree (documents attached help; leaves fall back to item_id).
Procedure: leaves take a few words from title or text; parents merge child tokens.
Result: a dict node_id → str, stored as a named set. Linkage fingerprint must not change.

from orchard import label_intrinsic

label_intrinsic(tree, name="intrinsic_v1")
tree.label_for(tree.root_node_id)          # active set
# max_words=4 by default
label_intrinsic(tree, name="short", max_words=2, make_active=False)

Import your own names

from orchard import import_labels

import_labels(
    tree,
    {tree.root_node_id: "All items"},
    name="imported",
)
tree.use_labels("imported")

Unknown node IDs raise. Extra nodes may be omitted; they just have no string in that set.

Switch sets

tree.use_labels("intrinsic_v1")
tree.use_labels("imported")
tree.use_labels(None)          # no active names; walk helpers show ids

Replacing a set never mutates linkage, memberships, or canonical IDs. Saved orchards store every named set under trees/<id>/labels/.
