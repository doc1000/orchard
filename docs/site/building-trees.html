Building Trees

from orchard import OrchardBuilder, DomainTaxonomy, FunctionTaxonomy

# defaults: domain + function
orchard = OrchardBuilder().build(documents)

# semantic only
orchard = OrchardBuilder(taxonomies=[]).build(documents)

# explicit taxonomies
orchard = OrchardBuilder(
    taxonomies=[DomainTaxonomy.load_default(), FunctionTaxonomy.load_default()]
).build(documents)

Inspect config with builder.get_params(). Default semantic backend is offline TF-IDF.
