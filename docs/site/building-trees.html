Building Trees

from orchard import OrchardBuilder, DomainTaxonomy, FunctionTaxonomy, SimilarityProfile
from orchard.backends.tfidf import TfidfEmbeddingBackend

# neural extras (or injected MiniLM + heads): fused domain + function
builder = OrchardBuilder()
orchard = builder.build(documents)
params = builder.get_params()  # fusion_mode, per-tree weights, backends

# clean-env / CI: single-layer cue JS + TF-IDF
orchard = OrchardBuilder(allow_offline_fallback=True).build(documents)

# semantic only (explicit TF-IDF)
orchard = OrchardBuilder(
    taxonomies=[],
    embedding_backend=TfidfEmbeddingBackend(),
).build(documents)

# override a tree profile (weights must sum to 1)
orchard = OrchardBuilder(
    profiles={"domain": SimilarityProfile(name="domain", weights={"domain_raw_js": 1.0})}
).build(documents)

Default neural profiles are MiniLM + document TF-IDF + taxonomy Jensen–Shannon, fused with variance_calibrated (n≥3). Tree names stay domain / function / semantic — there is no tree named fused.
